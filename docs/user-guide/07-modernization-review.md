# 7. Modernization Review

Start from Overview's **Start Priority Review**. The queue orders unresolved critical/high risks first, then other transparent factors; no AI score replaces those factors.

Inspect identity, recommendation, risk, reasons, source/database evidence and proposed target. Structural excerpts are bounded and may omit literals or sensitive context; inspect authorized local source for exact values.

| Action | Meaning |
|---|---|
| Accept | Accept the engine direction for current evidence |
| Change | Choose a supported alternative with rationale |
| Needs Review | Keep unresolved; record the missing decision |
| Defer | Postpone; remains unresolved |
| Needs Revalidation | Previous history no longer applies to current evidence |

Critical changes require explicit confirmation and rationale. Reviewer identity is server-derived. Engine evidence is not edited by a human override. Annotations have independent history.

Bulk selection first previews eligibility/exclusions. Ordinary bulk acceptance requires conservative LOW/mechanical/current evidence; AUTO alone is insufficient. Critical, manual, stale and sensitive findings cannot bypass policy. Concurrent changes invalidate the preview.

Review completion means applicable Accepted/Changed decisions, not code approval, generation authorization or migration completion. See [governance contracts](../modernization-review.md).
