# 1. Getting started

FormsLang inventories Oracle Forms and related database source, correlates evidence, prioritizes modernization decisions and produces reviewed delivery artifacts. It does not replace your Oracle architect or UAT.

For a first look, launch FormsLang and choose **Explore Demo Project**. The small synthetic dispatch application uses the same project creation, analysis and persistence path as your own sources. No account, AI provider, database or Oracle tooling is needed.

For your application:

1. Choose **New Project**. Enter a name.
2. Select Forms and database source folders. Inspect discovery warnings.
3. Keep the Oracle APEX 26.1 / APEXlang target.
4. Choose **Analyze Project**.
5. Read **Overview**, then **Start Priority Review**.
6. Accept, change, defer or request more information with evidence.
7. In **Generate**, prepare and review an eligible module's architecture, prerequisites and code.
8. Explicitly validate generated artifacts; export reports and a modernization package.

A useful assessment does not require generation eligibility. Complex modules can remain blocked while you deliver an assessment and review backlog. See the [manual checklist](../manual-validation-2.0.md) for expected outcomes.
