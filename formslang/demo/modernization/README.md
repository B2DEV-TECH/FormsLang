# Synthetic dispatch desk

Two hand-authored Forms2XML representations and a small database source set.
All names, logic and data are synthetic; this is not customer material and not
an Oracle Forms export or Oracle-validated runtime application.

Explore API delegation, an embedded lookup duplicated in a shared API, native
confirmation, unsafe MAX+1 key allocation, modal navigation, and a database
identity default that needs human review. The unsafe patterns are intentional.

The demo uses the normal project analysis engine, without fixture-specific rules,
AI, database credentials or Oracle tooling. Copies are independent and editable.
Nothing in these SQL files is executed. Analysis is not proof of functional parity.
